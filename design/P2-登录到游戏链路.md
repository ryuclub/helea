# P2 登录→进游戏 链路打通记录

> 状态：登录→选角→拿到 gameserver 移交信息 ✅（2026-06-14）

## 已验证链路（浏览器 WS → 网关 → loginserver）

```
CL_LOGIN(153)        → LC_LOGIN_OK(445)
CL_GET_PC_LIST(150)  → LC_PC_LIST(446)          角色列表
CL_SELECT_PC(159)    → LC_RECONNECT(450)        gameserver IP/port/key
```

测试：`web/gateway/test/selectpc.live.test.js`（账号 111111，Slayer SLOT1）。
结果：`LC_RECONNECT → gameserver=127.0.0.1:9998`。

## 协议层产物

- `src/codecs.manual.js`：CL_LOGIN / CL_GET_PC_LIST / CL_SELECT_PC（encode）、
  LC_LOGIN_OK / LC_LOGIN_ERROR / LC_RECONNECT（decode），均实测。
- CL_SELECT_PC 的 pcName 按 DB 原始字节(latin1)发送；pcType 0=Slayer 1=Vampire 2=Ousters。

## 服务端补丁（本地研究，让链路跑通）

| 文件 | 改动 | 原因 |
|---|---|---|
| `docker/docker-compose.local.yml` | MySQL 加 `--skip-character-set-client-handshake --character-set-server=latin1 --collation-server=latin1_swedish_ci` | MySQL8 默认 utf8mb4 与 latin1 列比较抛「Illegal mix of collations」断连 |
| `src/Core/SocketOutputStream.cpp` (writePacket) | **写完 body 回填真实长度到 size 字段** | 根治：多包 getPacketSize() ≠ write() 实际字节，接收端按错值分帧→整流错位。通用修复，所有变长包受益 |
| `src/Core/SocketOutputStream.h` | 加 markTail()/patchUIntAt() 访问器 | 支持回填 |
| `src/Core/Packet.h` (writeHeaderNBody) | 同样回填真实长度 | gameserver Zone 发包路径(Zone.cpp/ZonePlayerManager.cpp 用此路径) |
| `src/Core/LCPCList.cpp` (getPacketSize) | 补算槽位标记 + m_Agree | 局部修正(被 writePacket 回填覆盖，保留以保 getPacketSize 准确) |

## 数据修正

- `DARKEDEN.Player.CurrentServerGroupID`：测试账号 111111/222222 由 1 改 0，
  与 `GameServerInfo.GroupID=0` 对齐，否则选角时 zone→ZoneGroup→GameServerInfo 解析失败。

## 构建注意

docker 挂载存在**时钟偏差**：host 改源码后 mtime 可能落后于容器内对象文件，
cmake 增量构建会**跳过重编**。改动核心头/文件后需 `touch` 再 `cmake --build`，
或确认「重编文件数 > 0」。
