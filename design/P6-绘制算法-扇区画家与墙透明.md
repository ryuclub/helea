# P6 绘制算法：扇区画家算法 + 墙透明（替换 z-buffer 深度 hack）

> 来源：精读 research/client `MTopView.cpp` 等。这是原版**正确**的深度机制, 替换我们当前的
> "每物件一个 z(按底边) + 深度偏置 + 烤扁平物件" 这套对不齐的 hack。

## 关键前提：逻辑网格是矩形, 不是错排菱形
- `MapToPixel(x,y)=(x*48, y*24)`(MTopView.h:214; TILE 48×24, MViewDef.h:35)。无 `x±y` 菱形变换。
- 等距菱形外观来自**地砖美术本身**(48×24 菱形位图四角透明)。逻辑坐标是标准矩形。
- → 深度顺序 = **按网格行 y(北→南)逐行 painter's**, 行内再按 Viewpoint/PixelY 交错。不要用单一连续 z。

## 主绘制循环(MTopView::DrawZone, MTopView.cpp:11636; 核心 13452-13803)
可见扇区: 玩家居中, sX1..sX2(宽16), sY1..sY2(高25)。外层 y(北→南), 内层 x(西→东)。
```
// 阶段A: 地砖背景层(整片, 最底) —— TileSurface 缓存 blit
// 阶段B: 阴影层(物件阴影 + 生物阴影), 整批
// 阶段C: Viewpoint < sY1 的远景物件先吐
// 阶段D: 逐行交错(painter's 核心):
for y in [sY1..sY2]:                 // 北→南
    for x: drawGroundItems(x,y)      // 地面物品
    while io.peek.Viewpoint <= y: drawImageObject(io.next)   // 该行物件(按 Viewpoint 排序)
    while cr.peek.Y <= y:        drawCreature(cr.next)        // 该行生物(按 PixelY 排序)
    if player.Y == y: drawCreature(player)
    for x: drawEffects(x,y)          // 特效在生物之上
```
- 物件排序 key = `(Viewpoint<<32)|ID`(MTopView.h:316); 生物 = `(PixelY<<32)|ID`。
- **物件深度 = Viewpoint(编辑器预设的整数行号, 可能故意≠几何位置)**; 生物深度 = GetY()/PixelY。两者用同一个 y 闸门交错 → 南边(更近)物件画在角色之上、北边画在角色之下。
- 坐标: `screen = pixelX/pixelY - m_FirstZonePixel`(滚动原点)。物件无 cX/cY; 生物有 sX/sY 格内平滑偏移。

## 墙透明：原版"走到墙后看见自己"的真正实现(不是深度遮挡!)
`MTopView::DrawImageObject`(MTopView.cpp:16002): 物件半透明绘制的三条件:
```
trans = obj.IsTrans()                       // 物件标记可透明
     && obj.Viewpoint >= player.Y           // 物件会挡住玩家(在玩家行或更南)
     && obj.IsWallTransPosition(player.X, player.Y)  // 玩家确实在墙"后侧"
```
`IsWallTransPosition`(MImageObject.cpp:177): 按墙朝向 `objSX = pixelX/48`:
- WALL_RIGHTDOWN: 玩家 `sX-sY > objSX-Viewpoint` → 透明
- WALL_RIGHTUP:   玩家 `sX+sY < objSX+Viewpoint` → 透明
- 非墙: 默认 true
透明绘制只对**与玩家精灵包围盒相交的那块**做 alpha 混合(BltSpriteAlphaFilter + filter rect, 16019-16080), 其余墙体照常不透明 → "墙后透出角色轮廓"。

## Web 复刻方案
- 不用 z-buffer 自动深度。改: 每帧把可见 物件+生物 按 **(行 y 主序; 同 y 内 物件先于生物; 生物按 PixelY 细排)** 排序, 用 `renderingGroupId` 或递增 z 严格复现绘制序。地砖单独最底层。
- 物件深度键改读 **Viewpoint**(非精灵底边)。
- 墙透明: 对 isTrans 且会挡玩家的物件, 在与玩家重叠区域做半透明(可用 Babylon alpha + 仅该物件; 进一步可做"仅相交区"——初期整件半透明也可接受)。
- 这套做完: 角色被局部遮挡(铺地/楼梯/墙)整类问题消失, 且与原版一致。
