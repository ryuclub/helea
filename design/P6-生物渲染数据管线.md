# P6 数据驱动生物渲染管线（替换硬编码动作号）

> 来源：精读 research/client。原版用一条通用管线渲染**所有**生物(人类/吸血鬼/魔灵/怪/NPC/其他玩家),
> 不逐个硬编码。替换我们当前"肉眼试出 Slayer 站3/走7"的 hack。

## 三层间接 + 两套 action 命名空间
### 资源定位链
```
creatureType
 → g_pCreatureTable[ct].SpriteTypes[0]            (CreatureTable, Creature.inf)
 → g_pCreatureSpriteTable[spriteType].FrameID     (CreatureSpriteTable, CreatureSprite.inf)
 → m_CreatureFPK[FrameID][action][dir][frame].SpriteID   (cfpk 帧包)
 → m_CreatureSPK[spriteID]                         (ispk 像素)
```
- 普通怪/NPC/未进阶玩家: 身体全在**单一大包** `Creature.cfpk`/`Creature.ispk`, 纯数字 ID 索引。
- 进阶职业玩家(advancementLevel>0): 身体走按种族×性别的分包(`acslayerman`/`advancedvampireman`… ac=advancement class)。
- 表本体: `Data/Info/Creature.inf` + `CreatureSprite.inf`(GameInitInfo.cpp:731,763)。文件名经 g_pFileDef 配置读, 不在 C++。

### action 索引(关键)
- 服务器只发**基础 action**(0~34, 全种族共用): STAND=0, MOVE=1, ATTACK=2, MAGIC=3, DAMAGED=4, DRAINED=5, DIE=6 (MTypeDef.h:98)。`ADVANCEMENT_ACTION_START=100`。
- 绘制时(GetCreatureActionCountMax, MCreature.cpp:391):
  - **非进阶**(怪/NPC/未进阶玩家): `action` 直接当 cfpk 下标。✅ 最简起步只需这条。
  - **进阶玩家**: 按种族用重映射函数转成 ≥100 的进阶 action, 再 -100 索引进阶分包:
    - Slayer: `ConvAdvancementSlayerActionFromSlayerAction`(MTopViewDraw.cpp:409; 按右手武器 ItemClass 分流站/走/受击外观)
    - Vampire: `GetAdvancementVampireActionFromVampireAction`(190; 纯查表)
    - Ousters: `ConvAdvancementOustersActionFromOusterAction`(440; 按 bChakram 分流)
    - 返回 -1 = 无对应帧, 不绘制。

## GC_ADD 系列包(明文; 字符串=u8长度+字节; ObjectID=4,Coord/Dir=1,Color/HP=2,Alignment=4)
| 包 | id | 字段 |
|---|---|---|
| GCAddMonster | 183 | ObjectID, MonsterType(2), name, MainColor,SubColor, X,Y,Dir, EffectInfo(变长), CurHP,MaxHP, FromFlag |
| GCAddNPC | 189 | ObjectID, name, NPCID(2), SpriteType(2,忽略), MainColor,SubColor, X,Y,Dir |
| GCAddSlayer | 192 | PCSlayerInfo3 + EffectInfo + PetInfo + NicknameInfo + StoreOutlook |
| GCAddVampire | 195 | PCVampireInfo3 + 4子结构 + FromFlag |
| GCAddOusters | 190 | PCOustersInfo3 + 4子结构 |
- PCSlayerInfo3(read): ObjectID, name, X,Y,Dir, Outlook外观位集(4), Colors[9]×2, MasterEffectColor(1), CurHP,MaxHP, AttackSpeed(1), Alignment(4), Competence(1), GuildID(2), UnionID(4), Rank(1), AdvancementLevel(1)。
- 怪 MonsterType==creatureType(直接相等); NPC NPCID==creatureType。三者共用同一管线, 不同 creatureType 数值段。
- 子结构跳过: EffectInfo=u8 N + 4N; PetInfo=u8 type(PET_NONE 止)+…+ObjectID; NicknameInfo=WORD+BYTE 按 type; StoreOutlook=u8 Open(0止)+u8 len+len。

## 移动/删除
- GCMove id **282**: ObjectID(4),X,Y,Dir (他人移动)。
- GCDeleteObject id **232**: ObjectID(4) (离开视野/消失)。
- 三件套: 进视野 GCAddXxx(全量) → GCMove → GCDeleteObject。

## Web 复刻：最小可行(他人玩家未进阶 + 普通怪, 只身体, 站立+移动)
1. 从 Creature.inf/CreatureSprite.inf 导出表(creatureType→SpriteTypes[0]→FrameID); 加载 Creature.cfpk/.ispk。
2. 解码 GCAddMonster/AddSlayer/.../GCMove(282)/GCDeleteObject(232), 维护 world[objectID]={creatureType,x,y,dir,action}。
3. 渲染: spriteType=Table[ct].SpriteTypes[0]; body=SpriteTable[spriteType].FrameID; 非进阶 → action 直接下标 → CreatureFPK[body][action][dir][frame] → SPK 像素。
4. 进阶玩家(advancementLevel>0)再接三个重映射函数 + 分包。
- 这条做好: 种族/怪/NPC/其他玩家**默认渲染**, 不再逐个硬编码。当前 Slayer 主角也改走此管线(查表选 body, 而非肉眼试 action)。
- 装备/护甲是 addon 多层(可后置, 不影响身体定位)。
